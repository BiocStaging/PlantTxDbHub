# PlantTxDbHub 0.99.0

## NEW FEATURES

- First release of the package.
- Provides **TxDb** annotation databases for three plant species via `AnnotationHub`:
  - *Arabidopsis thaliana* (TAIR10, Ensembl release 62)
  - *Oryza sativa* (IRGSP‑1.0, Ensembl release 62)
  - *Glycine max* (Wm82 v2.1, Ensembl release 62)
- Data hosted on Zenodo and downloaded on‑demand using `BiocFileCache`.
- Includes a vignette demonstrating how to retrieve and use the TxDb objects.
